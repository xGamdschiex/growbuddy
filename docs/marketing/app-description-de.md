## Full Description (max 4000 Zeichen)

```
🌱 GrowBuddy — Dein digitales Grow-Tagebuch

GrowBuddy hilft Hobby-Gärtnern, ihre Pflanzen über den gesamten Wachstumszyklus
zu dokumentieren — von der Aussaat bis zur Ernte. Funktioniert offline, lokale
Datenhaltung, optionale Cloud-Synchronisation.

✨ FEATURES

📊 GROW-JOURNAL
• Mehrere Grows parallel verwalten
• Tägliche Check-ins mit Foto, EC, pH, VPD, Temperatur, Luftfeuchte
• Wachstumsphasen (Sämling, Vegetation, Blüte, Trocknung, Curing)
• Streak-System für tägliche Disziplin

🧪 DÜNGER-RECHNER (8 Düngerlinien)
• Athena Pro Line + Blended (Mineraldünger)
• BioBizz Organic (Light-Mix / Coco)
• CANNA Terra + Coco A+B
• Green House Powder Feeding (Hybrids, Short Flowering, Grow)
• Atami B'cuzz, Advanced Nutrients Sensi pH Perfect, Hesi Soil
• Auto-Faktor (linear T1 → T7), CalMag-Berechnung, Cleanse-Rampe (Athena)
• Pro-Tipps pro Phase und Woche (z.B. "PK 13/14 nur Bloom W4-6")

📈 INSIGHTS
• Statistiken pro Strain (Yield, Dauer, Score)
• Phase-Verteilung und Trend-Analysen
• Total-Yield, Anzahl Check-ins, Strain-Vielfalt

🌬️ WISSENSCHAFTLICHE BERECHNUNGEN
• VPD (Vapor Pressure Deficit) live aus Temp + RH
• EC-Einheit-Konvertierung (mS/cm, ppm500, ppm700)
• Phasen-spezifische Zielbereiche (Veg, Bloom)

💾 DATENHOHEIT
• 100% lokale Speicherung (localStorage)
• Backup-Export als JSON-Datei
• Optional: Cloud-Sync via Supabase (EU-Server)
• Keine Werbung, kein Tracking, keine Datenanalyse durch Dritte

🌍 COMMUNITY (optional)
• Eigene Grows als "Public" markieren
• Feed mit Posts anderer Grower
• Like, Follow, Report-System

⚙️ SONSTIGES
• Mehrsprachig (Deutsch, Englisch)
• Adaptive Icons + Material Design
• Dark Mode (default)
• Tägliche Erinnerungs-Notifications

🔒 DATENSCHUTZ
GrowBuddy speichert deine Daten primär lokal auf deinem Gerät. Cloud-Sync
ist optional und benötigt einen Account (E-Mail oder Google OAuth). Keine
Werbung, kein Tracking, keine Verkäufe an Dritte.

Datenschutzerklärung: https://growbuddy.app/privacy

📧 FEEDBACK
Beta-Phase — dein Feedback hilft uns, GrowBuddy zu verbessern:
feedback@growbuddy.app

⚠️ HINWEIS
GrowBuddy ist ein generelles Plant-Care-Tool und ersetzt keine professionelle
Anbau-Beratung. Bei Anbau in Deutschland: Bitte aktuelle Gesetzeslage zu
Eigenbedarf prüfen (CanG seit 2024).

🌱 Made in Mainz · Hobby-Projekt eines passionierten Gärtners.
```
